## DNN python scripts

#### Requirements

- Python: 3.10.13
- TensorFlow: 2.16.2
- Keras: 3.10.0


This folder contains four components:
- `DNNfunctions`: This contains all the functions (normalization, plotting, etc) that will be called while training and testing of the DNN.
- `train_DNN`: This is the main script used for training the DNN.
- `cases_DNN`: This is the main script which tests the trained DNN for different cases.
- `outputs`: The output pdfs, text files and the model (h5 file) will be saved here. 

To run the python scripts: `./<filename.py>`
