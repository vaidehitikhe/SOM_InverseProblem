## SOM python scripts

This folder contains six components:
- `Training_functions.py`: This contains the functions required to train the SOM.
- `Training_SOM.py`: This is the main script which calls the functions used of training and trains the SOM. 
- `Test_functions.py`: This script defines the functions (score, plotting, ROC, etc.) that will be called while testing a trained SOM model.
- `Testing_SOM.py`: This script loads and tests a trained SOM model.
- `Cases_SOM.py`: This script will use test functions and evaluate the cases. 
- `outputs`: The generated pdfs (training, testing and cases) as well as the trained SOM model (.p file) will be saved here. 

To run the scripts: `python3 <filename.py>`
